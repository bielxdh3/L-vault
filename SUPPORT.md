# Support

L-Vault is under active development and does not provide a commercial support SLA.

## Bugs

Use the GitHub bug-report form with:

- L-Vault version or commit;
- Windows/Python version;
- affected command or component;
- reproduction steps using disposable data;
- sanitized logs when useful.

Do not post OAuth credentials, tokens, cookies, passwords, databases, Gmail exports, Takeout archives, backup contents, device identifiers, or private filesystem paths.

## Setup and usage

Start with:

- [README.md](README.md)
- [SETUP_WINDOWS.md](SETUP_WINDOWS.md)
- [docs/disk-clone-offline.md](docs/disk-clone-offline.md)

If documentation does not answer the problem, open an issue with the minimum safe information needed to reproduce it.

## Feature requests

Use the feature-request form and explain the user or recovery problem first.

## Security

Do not report vulnerabilities in a public support issue. Follow [SECURITY.md](SECURITY.md).
